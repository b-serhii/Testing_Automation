ЛАБОРАТОРНА РОБОТА №7 — PLAYWRIGHT. ВАРІАНТ №1.

ВИКОНАНО:
— 17 тестів (15 з показових частин 2–7 та 2 окремі тести варіанта №1).
— Код TypeScript, конфігурація Playwright, тестовий файл для upload, Git-історія.
— Word-звіт із титульною сторінкою, лістингами, поясненнями й локальним скриншотом.

ПЕРЕД ЗДАЧЕЮ ПОТРІБНО ЗРОБИТИ 2 РЕАЛЬНІ СКРИНШОТИ З MAC І ДОДАТИ ЇХ У ЗВІТ.
Причина: середовище підготовки блокує npm registry і зовнішній браузерний доступ; реальний запуск на the-internet.herokuapp.com не підтверджено. Локальна перевірка Python Playwright НЕ є запуском готових тестів TypeScript.

КРОК 1. РОЗПАКУВАТИ
Завантажити ЛР_7_Playwright_проєкт_з_Git.zip і розпакувати. Відкрити Terminal:

cd ~/Downloads/qa-automation-lab7

Якщо папка в іншому місці, уведи cd і перетягни папку з Finder у Terminal.

КРОК 2. ВСТАНОВИТИ ПАКЕТИ ТА БРАУЗЕР

npm install
npx playwright install chromium

КРОК 3. ЗАПУСТИТИ ВЕСЬ НАБІР

npm test

У проєкті реалізовано 17 сценаріїв; усі повинні проходити після успішного запуску. ОЧІКУВАНИЙ підсумок: 17 passed. Якщо тест не пройшов — скопіюй реальну помилку й виправ її, а не вказуй вигаданий результат.

КРОК 4. ІНДИВІДУАЛЬНИЙ ВАРІАНТ №1

npm run test:variant

Два тести перевіряють на https://the-internet.herokuapp.com/add_remove_elements/ послідовність 0→1→2→3→4→5→4→3. Перший видаляє перший елемент двічі, другий — останній, а потім перший. Очікуваний підсумок: 2 passed.

КРОК 5. HTML-ЗВІТ І СКРИНШОТИ

npx playwright show-report --port 9325

Відкрий http://localhost:9325. Зроби скриншот успішного прогону в терміналі та HTML-звіту. Встав їх у розділ 10 Word-звіту замість двох рамок-заповнювачів. Якщо порт зайнятий, обери --port 9326.

КРОК 6. ДОДАТКОВО FIREFOX (НЕ ОБОВ’ЯЗКОВО ДЛЯ ЛР №7)
У ЛР №6 Firefox на цьому Mac потребував коректного профілю. Якщо хочеш показати другий браузер:

npx playwright install firefox
mkdir -p "$HOME/.playwright-firefox-home" "$HOME/.playwright-firefox-data" "$HOME/.playwright-firefox-local"
export CFFIXED_USER_HOME="$HOME/.playwright-firefox-home"
export MOZ_APP_DATA="$HOME/.playwright-firefox-data"
export MOZ_LOCAL_APP_DATA="$HOME/.playwright-firefox-local"
npm run test:firefox -- --workers=1

КРОК 7. GIT

 git log --oneline --reverse
 git branch --show-current
 git remote -v

Якщо потрібно додати remote зі своїм старим GitHub-репозиторієм:

git remote add origin https://github.com/b-serhii/Testing_Automation.git
git push -u origin lab7-variant1

В архіві створено окрему історію лабораторної №7. Це нова, незалежна за Git-графом гілка; вихідний код і коміти ЛР №6 не перезаписано. Якщо викладач вимагає саме продовження старої історії, необхідно перенести коміти в основний репозиторій.

ВАЖЛИВО ПРО ТАБЛИЦЮ
Методичні вказівки містять суму 203 долари. На офіційному сайті значення Due: 50 + 51 + 100 + 50 = 251 долар. У тесті та звіті вказано фактичну суму 251 доларів. Це не пропуск вимоги, а виправлення неточності прикладу.

ЯКЩО САЙТ НЕДОСТУПНИЙ
Викладач може надати адресу локального стенду. Тоді:
BASE_URL=http://localhost:3000 npm test

Не застосовуй явні waitForTimeout, не вмикай загальні довгі паузи. Надішли повний текст реальної помилки для уточнення.
